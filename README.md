**Auto Console Log** is a lightweight and powerful VS Code extension that automatically adds `console.log()` statements to all declared variables and constants in your JavaScript, TypeScript, and React files — saving you time and improving your debugging experience.

> 🔧 Built by **[Vallarasu Kanthasamy](https://www.vallarasuk.com/)** — a passionate React Developer focused on building dev productivity tools.

---

## 🔥 Features

- ✅ Automatically logs all declared variables and constants using `console.log()`
- ✅ Supports JavaScript, TypeScript, and React (.jsx/.tsx) files
- ✅ Customizable log levels: `log`, `info`, `warn`, `error`
- ✅ Works with a single shortcut for the **entire file**
- ✅ Saves valuable debugging time for real-world developers

## ⚙️ Usage – Super Simple & Powerful

> Just hit the shortcut, and BOOM 💥 — all your variables are console-logged in milliseconds!

### 🖥️ Shortcut Keys

| System             | Shortcut                                | Description                  |
| ------------------ | --------------------------------------- | ---------------------------- |
| 🪟 Windows / Linux | **Ctrl + Shift + L**                    | Logs all variables instantly |
| 🍎 macOS           | **Cmd + Shift + L**                     | Logs all variables instantly |
| 🧭 Command Palette | `Ctrl + Shift + P` → `Add Console Logs` | Manual run via menu          |
