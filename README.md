**Auto Console Log** is a lightweight and powerful VS Code extension that automatically adds `console.log()` statements to all declared variables and constants in your JavaScript, TypeScript, and React files — saving you time and improving your debugging experience.

> 🚀 Built by **[Vallarasu Kanthasamy](https://www.vallarasuk.com/)** — a passionate React Developer with real-world experience in building dynamic web applications and developer tools.

---

## 🔥 Features

- Automatically logs all declared variables and constants using `console.log()`.
- Supports JavaScript, TypeScript, and React (.jsx/.tsx) files.
- Customizable log levels: `log`, `info`, `warn`, `error`.
- Supports keyboard shortcut for instant use.
- Ideal for developers who want to boost productivity during debugging.

## 📦 Installation

Install directly from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=VallarasuKanthasamy.auto-console-log-by-vallarasu-kanthasamy) or via VS Code:

1. Open Extensions (`Ctrl+Shift+X`)
2. Search for `Auto Console Log By Vallarasu Kanthasamy`
3. Click **Install**

---

## ⚙️ Usage

Press the shortcut key to insert logs for all declared variables/constants in the active file:

- **Windows/Linux**: `Shift + Alt + Ctrl + L`
- **Mac**: `Cmd + Alt + Shift + L`

You can also run it from the Command Palette (`Ctrl+Shift+P`) and search:  
**`Add Console Logs`**
