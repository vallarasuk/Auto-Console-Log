# Auto Console Log By Vallarasu Kanthasamy

This VS Code extension automatically adds console log statements to all declared variables and constants in JavaScript files.

## Features
- Automatically logs all declared variables and constants using `console.log()`.
- Customizable to log in a specific format.

## Installation
1. Download the `.vsix` file or install directly from the Visual Studio Code marketplace.
2. Use the command palette to activate the extension.

## Usage
Press `Shift + Alt + Ctrl + L` to automatically add console logs for all declared variables/constants.
